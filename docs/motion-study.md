# Reference motion study — 19 September 2026

## What was inspected

Live desktop pages, DOM media inventory, multiple scroll positions and successive
animation states. These observations describe the references, not Mutuals capabilities.

### Memorable — https://www.memorable.sh/

- The opening field is an animated canvas of characters with a colored luminous
  volume. Headline characters resolve in sequence. This is distinct from the video.
- A separate launch-film section plays a muted, looping MP4 with an unmute control:
  `/home/hero/memorable-latest.mp4`. The hero scales away as the film section enters.
- The main explanatory scene stays pinned. A compact branded plate rotates into
  an oblique view, then separates into four planes. The camera/composition settle;
  connecting lines and opposite-side callouts explain traces, synthesis, graph and
  retrieval. The graph has luminous nodes and links; thickness, lighting and
  perspective make the layers physical rather than a pile of flat feature cards.
- Setup has selectable install/setup/create states. Later sections use smaller
  canvas illustrations, progressive disclosure and horizontal social-proof content.
- Media inventory reported 15 canvases and one video element during this inspection.

### Maritime — https://maritime.sh/

- The ship-shaped particle hero is a looping video with a poster fallback:
  `/videos/marketing/hero-ship-dots.mp4?v=17`, approximately 33.54 seconds.
- The four product vignettes are composed UI scenes. A boot sequence becomes a
  file tree, chat and calendar; a terminal types commands then opens a document;
  an editor shows a training process; stacked terminal windows explain isolation.
  The small scenes use timed state changes, not a static screenshot behind each caption.
- Dashboard/CLI/SDK tabs combine recordings with code examples. The dashboard video
  `/videos/marketing/dashboard-instances.mp4` is approximately 11.8 seconds.
  On inspection the offscreen hero was paused while the visible dashboard played.
- Desktop and closing typography use canvas treatments. The inspected DOM contained
  22 canvases and two video elements. MCP setup uses a separate tabbed code panel.

### Agent37 — https://www.agent37.com/

The supplied screenshots' agent-selection and security approach was checked against
the live page. Its inspected DOM contained no canvas or video elements. The useful
pattern here is the recognizable colored agent selector, crisp request/result panel,
and restrained security explanation. Certifications and provider claims are not reusable.

## Mutuals adaptation

- Restore the existing portrait network: moving people, connecting lines, traveling
  signals and pointer/scroll parallax. Keep the central reading area quiet. Add a
  pause/resume control and retain reduced-motion support.
- Show original agent marks at natural brand colors in the hero and setup selector.
- Build an original, browser-rendered memory artifact rather than reuse reference
  films or artwork. Four perspective planes represent source notes, structured
  enrichment, relationships, and returned context. GSAP scrubs their separation
  through a native-scroll sticky scene. Mobile and reduced motion show expanded layers.
- Show an illustrative note-to-profile vignette: identify the person, extract new
  details, add two facts, preserve existing facts, and inspect the source. It plays
  once in view, completes in under four seconds, and has an explicit replay button.
- No automatic page scrolling, new animation framework, external video requests,
  fictional certification or unsupported performance comparison.

### Ecosystem revision

The merged ecosystem keeps the references' scroll-driven exploded-object approach:
three projected database plates separate vertically while a dashed signal moves
through the source/agent routes and an orbital ring advances. This is rendered
with CSS 3D transforms and inline SVG, rather than borrowing a reference video.
Portraits return in the hero as six fixed points on the network surface (four on
mobile), with consistent image crops and fine metallic rims.
